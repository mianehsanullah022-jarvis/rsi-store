# RSI Accessories — Online Store

Live: https://mianehsanullah022-jarvis.github.io/rsi-store/

Fast single-page store (no framework). Products, prices, stock and settings are managed in **RSI OS**:
https://mianehsanullah022-jarvis.github.io/rsi-os/

- Orders are saved in Supabase (free plan). Prices are always checked on the server.
- Payment: Cash on Delivery, JazzCash, Easypaisa, bank transfer.
- To use your own domain later: add a `CNAME` file with the domain and point DNS to GitHub Pages.
